Shady Deals — inspector demo

This page deliberately does everything the inspector looks for. Open the extension popup and check each tab.

1. Cookies

Sets one cookie without Secure, and the tracker script sets one on its own domain (a third-party cookie).

2. Requests

Loads tracker.js and sends a beacon POST to localhost:8791 — a different host from this page's 127.0.0.1, so it counts as third-party.

3. Forms

This login form posts your password to the tracker host, not here.





4. Storage + fingerprinting

Writes two localStorage keys and reads a canvas fingerprint.
