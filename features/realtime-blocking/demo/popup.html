Popup that opens itself

Phishing pages open extra tabs to show fake login screens. Olfa only closes tabs a page opened on its own — never a tab you opened.

Why a button? Chrome blocks window.open() on page load without a user gesture, so the demo needs one click to create the popup. What matters is the new tab's gesture state: navigator.userActivation.hasBeenActive is false there, so the extension is allowed to close it.
